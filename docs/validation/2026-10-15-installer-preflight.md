# 安装前运行检查与旧程序保留

日期：2026-10-15。范围：基于 `e552e60` 的安装脚本修复。

## 问题与修复

[Linux 包兼容性检查](2026-10-15-portable-release.md) 发现，归档校验和正确也可能因 glibc 版本而无法执行。安装器原先先覆盖目标 `senixd`，随后才调用 `--version`；新包不能运行时，安装虽返回失败，已有可用程序已经被替换，还输出了 `Installed`。

现在，安装器在临时解包目录中先执行候选文件的 `--version`。失败会保留原始运行错误并退出，目标程序不变；成功后才进行安装，输出此前取得的版本信息。SHA-256、受信 HTTPS 镜像要求和下载重试保持原规则。

## 实际回归

新增真实 Shell/HTTP 安装器 E2E：本机镜像服务器提供正确 SHA-256 的归档，候选文件故意返回运行失败，目标目录预先放置可用旧程序。测试在修改安装脚本前运行并失败，证明旧文件被覆盖；修复后通过，确认失败返回、原文件字节保持一致、旧程序仍可执行、没有错误输出安装成功。

该回归使用受控运行失败模拟加载错误，不声称本次在 macOS 上原生执行了 glibc 失败的 Linux 文件。真实 Linux 加载错误和归档摘要见前述兼容性记录。

- Rust 1.88 工作区 82 项通过，含 28 项真实进程 E2E；原有中断下载重试与正常安装仍通过。
- 格式、严格 Clippy、安装器 Shell 语法、README 资源及文档相对链接检查通过。
- 提交 `896513c` 的 [远端 CI](https://github.com/ALVIN-YANG/senix/actions/runs/38718901556) 全部通过，包含新增旧程序保留回归、82 项测试及两种 Demo 故障恢复。
- 验收只操作临时目录，没有安装到本机系统路径或替换用户已有程序。

此保护只针对替换前的运行失败，不将它描述为覆盖所有磁盘、权限或断电场景的原子安装。
