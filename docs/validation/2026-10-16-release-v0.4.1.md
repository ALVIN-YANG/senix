## 完整 AI 配置流程

四份安装包分别验证：读取配置 v1 → 按 Schema 和 `expected_version=1` 规划 → 未批准应用被拒绝 → 测试 Owner 批准精确计划 → MCP 应用到 v2 → 重复应用返回原结果。真实代理请求确认新域名为 200、无关路由为 200、旧域名为 404；重启后同一 Owner、Key、精确配置与代理结果保留。工具列表没有配置批准工具。[四包逐项结果](release-v0.4.1/2026-10-16/archive-mcp.json)。

两种公开镜像额外分别验证并发修改窗口：AI 读取 v1 后，Owner 新增路由并发布 v2；AI 用旧版本规划得到 `CONFIG_VERSION_MISMATCH`，且没有保存计划。重新读取并合并后，未批准应用仍被拒绝；测试 Owner 批准，MCP 应用到 v3，重复应用幂等。新域名与 Owner 并发新增域名均为 200、旧域名为 404；重启后同一账号、Key、精确 v3 与路由结果保留。另检查缺少 `expected_version` 被拒绝。
