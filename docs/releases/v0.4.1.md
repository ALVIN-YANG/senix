# Senix v0.4.1

This patch adds a Chinese/English admin console and improves the packaged getting-started guide. It also publishes reproducible streaming checks and a paced SSE baseline, including the observed HTTP/2 queueing limit.

## Changes

- **Chinese and English admin:** login, all six pages, forms, local messages and time formatting. Language selection follows the browser initially, then remembers the user's choice. Switching preserves drafts and selections without refreshing backend data. API values, configuration JSON, authorization and configuration semantics stay unchanged.
- **Archive onboarding:** a self-contained bilingual guide covers prerequisites, hidden password input, interrupted setup recovery, startup, real proxy requests and persistent data. Online references are pinned to the matching tag or source commit.
- **Monitoring acceptance:** the checker keeps traffic active across scrape intervals and retries cold-start connection closures within bounded limits, avoiding false failures during startup. Monitoring protocols and the gateway runtime are unchanged.
- **Streaming regression coverage:** real SSE delivery, bidirectional WebSocket messages and TLS/HTTP2 gRPC streams, including successful/error trailers and existing connections during draining. These extend verification; they do not add a new proxy protocol implementation.
- **Performance evidence:** a separate paced SSE workload retains raw event timings and independently checks counts, ordering, Unicode content, bytes and percentiles. Reports reject exports nested inside their input directory. Short-request results retain their original workload and source attribution.
- **Drain documentation:** an instance reaches `DRAINED` when both ordinary and long-lived in-flight counts reach zero. A recorded operation timeout remains a timeout while subsequent counters can still update; timeout does not force-close existing connections.

## Compatibility

There are no additional MCP or REST contract changes in this patch. The v0.4.0 migration still applies: `plan_change` requires `expected_version` from `get_current_config`. On a version mismatch, reread and merge the intended change into the current configuration. Owner approval remains bound to the exact immutable plan.

## Limits

At 128 virtual users over one HTTP/2 connection, the server advertised 100 concurrent streams and first-event p95 reached about 5 seconds. This includes queueing and initial connection costs; it is not a global gateway capacity limit. The paced workload uses synthetic events, not model inference or a saturation/soak test.

Senix remains a single-node gateway with a SQLite control plane. Native OTLP traces, multi-node consistency and multi-model task success-rate results are not provided. Prometheus/Grafana, VictoriaMetrics, OTel Collector metrics and Alloy/Loki have executed integration evidence; other monitoring examples are not all live-tested vendor integrations. gRPC wire checks do not establish generated-client interoperability or load capacity. Dependencies are unchanged and four previously recorded upstream RustSec warnings remain.

Please include your OS/architecture, Senix version, minimal configuration and sanitized errors when reporting a problem. Exclude Keys, passwords, Cookies and private certificate material.

## Try v0.4.1

Requires Git, Docker with Linux containers, Compose v2, curl, free ports 8080/9080 and an available 172.28.0.0/24 subnet.

```bash
git clone --branch v0.4.1 --depth 1 https://github.com/ALVIN-YANG/senix.git
cd senix
SENIX_IMAGE=ghcr.io/alvin-yang/senix:0.4.1 ./scripts/demo.sh
```

The demo prints the Owner password, admin URL and a real proxy response. Select English or 简体中文 on the login page.

Linux binaries require glibc 2.34 or newer. Archives cover Linux/macOS on x86_64/ARM64; container images cover Linux amd64/arm64.
