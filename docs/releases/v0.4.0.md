# Senix v0.4.0

Senix is a Rust gateway with scoped MCP tools and Owner-reviewed configuration changes. This release makes the AI configuration workflow available as downloadable binaries and a container image.

### What changes

- **Read, plan, review, apply:** MCP can read the complete configuration and version. The Owner approves the exact immutable plan before an agent can apply it.
- **Version-aware planning:** `plan_change` requires `expected_version` and exposes a configuration JSON Schema. A version mismatch rejects planning before saving a plan; read again and merge the requested change.
- **Scoped access:** admin Key presets cover read-only diagnostics, proposals and approved-change application. Approval remains an Owner action.
- **Observability:** request-duration histograms, optional JSON access logs and monitoring examples. Prometheus/Grafana, VictoriaMetrics, OTel Collector, Alloy and Loki paths were exercised. Other integrations have configuration examples; native trace export remains future work.
- **Onboarding and delivery:** interrupted Owner setup can recover, Linux packaging is checked on glibc 2.34, and an unrunnable download preserves the existing installation.
- **Evidence:** bilingual guides, real workflow records and reproducible performance data. The published performance baseline is tied to its recorded source and environment; it is not a capacity guarantee for this version.

### MCP migration

Existing callers of `plan_change` must add `expected_version` from `get_current_config`. Preserve the complete configuration and change only the intended fields. On `CONFIG_VERSION_MISMATCH`, reread and merge before retrying; changing only the version number on an old candidate can still replace someone else's edits.

REST v1 keeps its existing request format. `plan_rollback` keeps its existing contract.

### Try v0.4.0

Requires Git, Docker with Linux containers, Compose v2, curl, free ports 8080/9080 and an available 172.28.0.0/24 subnet.

```bash
git clone --branch v0.4.0 --depth 1 https://github.com/ALVIN-YANG/senix.git
cd senix
SENIX_IMAGE=ghcr.io/alvin-yang/senix:0.4.0 ./scripts/demo.sh
```

The script prints the generated Owner password, admin URL and a real proxy response. The admin UI is in Chinese; the English guide includes the corresponding labels.

To install the binary explicitly:

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://raw.githubusercontent.com/ALVIN-YANG/senix/v0.4.0/install.sh \
  | sh -s -- --version v0.4.0
```

Linux binaries target glibc 2.34 or newer. Archives cover Linux/macOS on x86_64/ARM64. The container image covers Linux amd64/arm64.

### Published-artifact verification

[Release validation and raw evidence](https://github.com/ALVIN-YANG/senix/blob/main/docs/validation/2026-10-15-release-v0.4.0.md) cover downloaded archives, actual installation, MCP changes and monitoring. For monitoring acceptance, use the [current checker](https://github.com/ALVIN-YANG/senix/blob/main/scripts/check-observability.py): post-release helper fixes keep test traffic active across scrape intervals and retry cold-start connection closures. The v0.4.0 binaries are unchanged.

### Limits and feedback

This is a single-node gateway with a SQLite control plane. There are no multi-node consistency guarantees, native OTLP traces or multi-model task success-rate results. Four upstream RustSec warnings remain documented. An earlier unexplained local Demo startup exit has not been established as fixed; the separately reproduced bootstrap and probe failures have regression coverage.

Please report your OS/architecture, Senix version, a minimal configuration and sanitized errors when reporting a problem. Do not include API Keys, passwords, Cookies or private certificate material.
